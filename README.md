## 🚀 Sobre o Projeto

O **Super Mario Bros Project** é uma landing page temática desenvolvida para praticar **interatividade em JavaScript**, manipulação de elementos na tela (modais) e estruturação de interfaces modernas. 

A ideia do site é criar uma experiência imersiva onde os clientes podem solicitar orçamentos e serviços de encanamento diretamente com os irmãos Mario e Luigi.

---

## ✨ Destaques & Funcionalidades

- **Formulário de Contato Modal:** Modal interativo que abre/fecha ao clicar no botão de orçamento.
- **Redirecionamento para WhatsApp:** Botão com link direto configurado para simular o atendimento rápido.
- **Interface Temática:** Design visual personalizado com cores, tipografia e elementos inspirados no universo do Super Mario.
- **Layout Responsivo:** Adaptado para navegação fluida em desktops e dispositivos móveis.
